# Travel Explorer Website

**Live Demo:** [https://travel-explorer.vercel.app](https://uiproject-seven.vercel.app)

## 📋 Project Overview
A fully responsive travel website built using HTML5, CSS3, and Bootstrap 5. This project showcases modern web design with multiple interactive components.

## 🚀 Features
- **Responsive Navigation** with search bar and hamburger menu
- **Image Carousel** with 3 slides and call-to-action buttons
- **Flex Layout** displaying 3 popular destinations
- **CSS Grid Gallery** with 9 travel photos
- **Bootstrap Cards** for travel packages with hover effects
- **Complete Footer** with contact info and social links
- **Mobile-First Design** optimized for all screen sizes
- **Smooth Animations** and transitions

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Icons:** Bootstrap Icons
- **Images:** Unsplash (free high-quality photos)
- **Hosting:** Vercel
- **Version Control:** Git & GitHub
